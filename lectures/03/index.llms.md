## Pratiquer

Pour ceux qui ne sont pas encore familiers avec `numpy` et `pandas`, il est recommandé d’explorer ces tutoriels dans les semaines à venir à votre propre rythme. Les notebooks d’Aurélien Géron offrent des informations essentielles sur les concepts de base de l’apprentissage automatique.

- [numpy](https://colab.research.google.com/github/ageron/handson-ml3/blob/main/tools_numpy.ipynb) – a fundamental library centered around N-dimensional array objects.
- [pandas](https://colab.research.google.com/github/ageron/handson-ml3/blob/main/tools_pandas.ipynb) – powerfull data analysis tools, centered around the `DataFrame`.
- [visualization](https://colab.research.google.com/github/ageron/handson-ml3/blob/main/tools_matplotlib.ipynb) – demonstrates how to use the `matplotlib` to produce beautiful graphs.

Dans les semaines à venir, vous pourriez souhaiter appliquer les concepts discutés en classe à une variété de jeux de données afin de développer davantage vos compétences et votre intuition. Vous trouverez ci-dessous une liste de sites web où vous pouvez trouver des jeux de données pertinents.

### Jeux de données de petite à moyenne taille, très adaptés aux étudiants

- [UCI Machine Learning Repository](https://archive.ics.uci.edu/)
- [Jeux de données jouets de scikit-learn](https://scikit-learn.org/stable/datasets/toy_dataset.html)

### Jeux de données plus importants

- [OpenML](https://www.openml.org/), s’intègre directement avec scikit-learn
- [PMLB (Penn Machine Learning Benchmarks)](https://epistasislab.github.io/pmlb/)

### Compétition(s)

- [Jeux de données Kaggle](https://www.kaggle.com/datasets)
  - Kaggle, une plateforme appartenant à Google, sert de communauté en ligne dédiée aux scientifiques des données et aux praticiens de l’apprentissage automatique. Elle facilite la participation à des compétitions de science des données, la collaboration sur divers projets, et offre un accès à des ensembles de données diversifiés. De plus, les utilisateurs peuvent construire des modèles en utilisant ses outils basés sur le web.
